READ ME: the idea of this project is to create a random episode generator for 'Bob's Burgers' that can be based off of vibe / main theme / characters / etc.
    EX: If someone wanted an episode that has Gayle in it, the code would recommend an episode that has Gayle in it
    EX: If someone wanted a Thanksgiving themed episode, it would randomly choose one of them
